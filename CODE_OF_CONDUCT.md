# Código de Conducta

Sé respetuoso. No se tolera acoso, ataques personales, lenguaje ofensivo ni publicación de datos privados de otras personas.

Los comentarios, issues y pull requests que incumplan esto pueden ser eliminados, y sus autores pueden ser expulsados del repositorio.

Reporta conductas abusivas de forma privada mediante un aviso de seguridad en GitHub: https://github.com/zkak0/k-removemark/security/advisories/new
